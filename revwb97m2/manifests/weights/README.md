# Training-weight evidence

`coach_si_table2_first_cycle.csv` is a manual transcription of COACH SI Table
2 in Sections 3.4-3.5. It contains the published first-cycle rows exactly and
adds explicit relationship warnings relative to the current GSCDB137 registry.

This directory records evidence. A future adopted revwb97m2 training-weight
file must have explicit GSCDB137 reaction IDs and must resolve the missing
later-cycle COACH weights, renamed/subset datasets, and the AE18 `Shrink2`
paper/code discrepancy.
